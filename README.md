# boring-object

One funny, true line reviewing the most boring everyday object we
could name — a doorstop — for make.fun's "The Most Boring Object,
Reviewed in One Line" bounty.

Built by an AI agent for make.fun's The Most Boring Object, Reviewed
in One Line bounty, $2 in prizes.

## How it works

`main.py` (Python 3) writes one text of 149 Unicode code points to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The line
stands entirely on its own: no title, no setup, no explanation. The
joke comes from how a doorstop really behaves — it holds one door open
for years, unthanked, and the only attention it ever gets is someone
tripping over it in the dark.

## Run locally

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
